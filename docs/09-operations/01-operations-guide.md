## 9.3 故障处理

### 9.3.1 故障分级

| 级别 | 定义 | 示例 |
|------|------|------|
| P0 | 系统完全不可用 | 数据库宕机、服务崩溃 |
| P1 | 核心功能不可用 | 登录失败、TV无法同步 |
| P2 | 非核心功能异常 | 报表生成慢、导出失败 |
| P3 | 轻微问题 | UI显示异常、日志报错 |

### 9.3.2 故障处理流程

```
故障发现
    │
    ▼
故障确认 ──► 是否P0? ──► 是 ──► 启动应急预案
    │              │
    │              └──► 否 ──► 常规处理
    │
    ▼
故障定位
    │
    ├─ 应用问题 ──► 查看日志 ──► 修复代码 ──► 发布修复
    ├─ 数据库问题 ──► 检查连接/慢查询 ──► 优化SQL/扩容
    ├─ 网络问题 ──► 检查网络状态 ──► 联系运营商
    └─ 硬件问题 ──► 切换备用节点 ──► 更换硬件
    │
    ▼
故障恢复
    │
    ▼
故障复盘 ──► 根因分析 ──► 改进措施 ──► 更新预案
```

### 9.3.3 常见故障处理

#### 故障1: TV同步失败率高

**现象**: TV同步成功率低于95%

**排查步骤**:
1. 检查网络状态 `ping tv-device`
2. 查看同步服务日志 `kubectl logs -f careld-sync`
3. 检查数据库连接池 `show processlist`
4. 查看同步队列积压 `redis-cli llen sync:queue`

**处理措施**:
- 网络问题：联系门店检查网络
- 服务问题：重启同步服务
- 数据库问题：优化慢查询/扩容
- 队列积压：增加消费者/清理过期数据

#### 故障2: 数据库连接数耗尽

**现象**: 应用报错 "Too many connections"

**处理步骤**:
```bash
# 1. 查看当前连接数
mysql -e "show status like 'Threads_connected';"

# 2. 查看连接来源
mysql -e "select host, count(*) from information_schema.processlist group by host;"

# 3. 临时增加连接数
mysql -e "set global max_connections = 1000;"

# 4. 杀掉空闲连接
mysql -e "select concat('kill ',id,';') from information_schema.processlist where command='Sleep' and time > 300;"

# 5. 重启应用释放连接
kubectl rollout restart deployment/careld-server
```

## 9.5 TV APK升级

### 9.5.1 升级策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 强制升级 | 必须升级才能使用 | 重大Bug修复、安全补丁 |
| 推荐升级 | 提示用户升级 | 新功能、性能优化 |
| 静默升级 | 后台自动下载安装 | 紧急修复 |

### 9.5.2 升级流程

```kotlin
/**
 * APK升级管理器
 */
class UpgradeManager(private val context: Context) {
    
    suspend fun checkUpgrade(): UpgradeInfo? {
        val currentVersion = getCurrentVersion()
        val response = apiService.checkUpgrade(
            deviceCode = getDeviceCode(),
            currentVersion = currentVersion
        )
        
        return if (response.data.hasUpgrade) {
            response.data
        } else null
    }
    
    fun downloadAndInstall(upgradeInfo: UpgradeInfo) {
        when (upgradeInfo.upgradeType) {
            "force" -> startForceUpgrade(upgradeInfo)
            "recommend" -> showRecommendDialog(upgradeInfo)
            "silent" -> startSilentUpgrade(upgradeInfo)
        }
    }
    
    private fun startForceUpgrade(upgradeInfo: UpgradeInfo) {
        // 显示强制升级弹窗，无法关闭
        AlertDialog.Builder(context)
            .setTitle("重要更新")
            .setMessage("请升级到最新版本")
            .setCancelable(false)
            .setPositiveButton("立即升级") { _, _ ->
                downloadApk(upgradeInfo.downloadUrl)
            }
            .show()
    }
    
    private fun downloadApk(url: String) {
        val request = DownloadManager.Request(Uri.parse(url))
            .setTitle("Careld升级")
            .setDestinationInExternalPublicDir(Environment.DIRECTORY_DOWNLOADS, "careld.apk")
            .setNotificationVisibility(DownloadManager.Request.VISIBILITY_VISIBLE_NOTIFY_COMPLETED)
        
        val downloadManager = context.getSystemService(Context.DOWNLOAD_SERVICE) as DownloadManager
        val downloadId = downloadManager.enqueue(request)
        
        // 监听下载完成
        registerDownloadCompleteReceiver(downloadId)
    }
}
```
