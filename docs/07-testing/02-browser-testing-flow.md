## 四、API 接口测试（使用 curl）

### 4.1 认证接口

```bash
# 登录（用户名）
curl -X POST http://localhost:8281/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123","loginType":1}'

# 登录（手机号）
curl -X POST http://localhost:8281/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"phone":"13900003001","password":"parent123","loginType":2}'
```

### 4.2 儿童档案接口

```bash
# 获取 token（先登录）
TOKEN=$(curl -s -X POST http://localhost:8281/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"phone":"13900003001","password":"parent123","loginType":2}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['data']['accessToken'])")

# 获取孩子列表
curl http://localhost:8284/api/v1/children \
  -H "Authorization: Bearer $TOKEN"

# 创建孩子
curl -X POST http://localhost:8284/api/v1/children \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"测试儿童","phone":"13900003001","birthDate":"2020-01-01","gender":1,"eyeCondition":"正常","storeId":1}'
```

### 4.3 通过 Vite 代理测试

```bash
# 家长端代理（5173 → auth-service 8281）
curl -X POST http://localhost:5173/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"phone":"13900003001","password":"parent123","loginType":2}'

# 家长端代理（5173 → child-service 8284）
curl http://localhost:5173/api/v1/children \
  -H "Authorization: Bearer $TOKEN"
```
