## 2. 现状诊断

- 列宽合计：120(日期) + 120(时段) + 100(姓名) + 70(性别) + 70(年龄) + 130(电话) + 100(状态) = **710px**。
- 用户截图中卡片宽约 728 CSS px，扣除 `el-card` 内边距 20×2 与边框，表格容器实测 **686px**（将卡片宽度设为 728px 后读取 `el-table` 容器得到）→ 溢出约 24px，表现为「状态」列被裁切、底部出现横向滚动条。
- 时段/性别/年龄三列内容短（`10:00-11:00`、单字、1–2 位数字），原宽度冗余最大，是收窄的首选。
