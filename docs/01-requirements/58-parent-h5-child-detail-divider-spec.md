## 2. 现状诊断

- #106/#107 后「档案信息」行序：档案编号 → 建档医院 → 服务电话 → 主治医师 → 儿童姓名 → 性别 → …，两组信息视觉上连续，无分隔。
- 卡片内既有分隔惯例：`.entry-row` 用 `border-bottom: 1rpx solid #f1f5f9`；全局边框色 `#e2e8f0`。本次为「分组」而非「行间分隔」，取对比度稍强的 `#e2e8f0`。

---

## 3. 改造设计

`frontend/parent-h5/src/pages/child/detail.vue`：

```html
<view class="kv"><text class="kv-key">主治医师</text>…</view>
<view class="kv-divider"></view>
<view class="kv"><text class="kv-key">儿童姓名</text>…</view>
```

```scss
.kv-divider {
  height: 2rpx;
  margin: 16rpx 0;
  background: #e2e8f0;
}
```

- 单位为 rpx（与本页其它行一致，编译为 rem 随视口缩放）：在 375px 宽设备上为 **1px 线、上下各 8px** 间距。
- 作为块级 `<view>` 默认宽度自动，与 `.kv` 行同宽（卡片内容区宽度）。
