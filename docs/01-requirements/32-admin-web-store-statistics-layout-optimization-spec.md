## 2. 现状诊断

弹窗「医院基本信息」区为 `el-descriptions :column="2"` 两列布局，改动前 13 个字段依序为：

```
医院编码    | 医院名称
机构性质    | 医院状态
所在地区    | 详细地址
联系人      | 联系电话
营业时间    | 加盟时间
床位数量    | 运营中心
代理商      |
```

「医院名称」在第 2 格、「机构性质」在第 3 格（跨行），二者视觉上并不相邻；营业时间占据第 9 格，导致末行落单。

## 3. 改造设计

仅调整 `frontend/admin-web/src/views/store/list.vue` 中弹窗内 `el-descriptions-item` 的书写顺序并删除一项，无逻辑、无接口、无类型改动。

改动后字段顺序（12 项，恰好 6 行 × 2 列）：

```
医院编码    | 机构性质
医院名称    | 医院状态
所在地区    | 详细地址
联系人      | 联系电话
加盟时间    | 床位数量
运营中心    | 代理商
```

说明：
- 对调后「机构性质」紧随「医院编码」，与医院列表表格列序（编码/名称/省市区/机构性质…）的差异属预期 —— 用户要求的是名称与性质对调，未要求与列表对齐。
- 「营业时间」仅从该弹窗移除；`StoreOverview.businessHours` 类型与后端返回字段保留不动（后端 DTO 仍完整，避免影响其它潜在消费方）。
- 弹窗标题 `${医院名称} - 数据统计` 已含医院名，对调后信息不丢失。
