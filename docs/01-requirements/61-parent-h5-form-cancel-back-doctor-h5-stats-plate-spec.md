## 2. 现状诊断

- **104-1**：原实现（`cancel()` / `confirmDiscard()` 确认分支 / 提交成功）统一调用 `uni.navigateBack()`。从列表页正常进入（页面栈长度 ≥ 2）时返回正常；但**直接打开或刷新建档页时页面栈只有 1 层**（真机复现：直接打开 `#/pages/child/form`，`getCurrentPages().length === 1`），此时 `navigateBack()` 无上一页可退，表现为「点击取消（含确认放弃）后停在原页」，即用户反馈的现象。
- **104-2**：三个球所在卡片 `.stats` 原为白底（`background: #fff`），与上方蓝色渐变 hero 区、球内浅蓝玻璃质感衔接不够，需改为很浅的蓝底。

## 3. 改造设计

### 104-1 `frontend/parent-h5/src/pages/child/form.vue`

新增统一返回函数，三处返回入口（`cancel()`、`confirmDiscard()` 的确认分支、提交成功后的延时返回）改走它：

```ts
/** 返回上一级；无上一级（直接打开或刷新本页）时回到儿童档案列表 */
function goBack() {
  if (getCurrentPages().length > 1) {
    uni.navigateBack()
    return
  }
  uni.switchTab({ url: '/pages/child/index' })
}
```

`pages/child/index` 是 tabBar 首项（儿童档案），故无栈回退用 `switchTab`。

### 104-2 `frontend/doctor-h5/src/pages/home/index.vue`

```scss
.stats {
  background: #eff6ff;  /* 原 #fff，很浅的蓝 */
  ...
}
```

仅改底板色，圆角 / 阴影 / 球体样式不变。
