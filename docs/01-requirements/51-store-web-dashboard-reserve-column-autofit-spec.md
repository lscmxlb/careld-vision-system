## 2. 现状诊断

- #103 后各列为固定 `width`（120/110/100/56/56/130/100，合计 672），在容器宽于 672 时右侧留白，窄于 672 时出现横向滚动——宽度不随区域变化。
- Element Plus `el-table` 默认 `fit=true`：列为固定 `width` 时不参与伸缩；改为 `min-width` 后，架容器有富余时剩余宽度按各列 min-width 比例分配，容器不足时可压缩至 min-width。

## 3. 改造设计

`frontend/store-web/src/views/dashboard/index.vue` 最近预约表格，7 列 `width` → `min-width`：

|---|---|---|---|
| 日期 | 120 | 105 | `2026-10-11` ≈ 79px + 内边距 24px ≈ 103px |

| 儿童姓名 | 100 | 90 | 4 字姓名 56px + 24px = 80px |

min-width 合计 627px。无脚本、类型、接口改动。

## 5. 遗留与说明

1. 容器宽度小于 627px（全部 min-width 之和）时仍会出现横向滚动，这是弹性布局的下限；用户当前容器约 686px，不受影响。
2. 门店 1 测试数据中 6 字姓名（「日志验证儿童」）在 90px 姓名列下折为两行——测试数据现象，用户门店 7 的 3–4 字姓名不受影响。
3. 应用内浏览器 0×0 无法截图，最终视觉效果以用户确认为准。
4. 右侧「养护记录」卡未改动（用户圈选范围为「最近预约」区域）；如需同样自适应可另提。
