## 一、快速使用

### 手动导入
```bash
mysql -u root -p careld_vision < database/mysql/test-data.sql
```

### Docker Compose 自动加载
测试数据已配置在 `deploy/init-scripts/02-test-data.sql`，MySQL 容器首次启动时自动执行。

加载顺序：
1. `deploy/init-scripts/01-init.sql` — 建表 + 基础数据
2. `deploy/init-scripts/02-test-data.sql` — 业务测试数据

## 十、数据统计

```sql
SELECT
  (SELECT COUNT(*) FROM sys_user)            AS '用户数',
  (SELECT COUNT(*) FROM store_info)          AS '门店数',
  (SELECT COUNT(*) FROM store_tv_device)     AS '设备数',
  (SELECT COUNT(*) FROM child_profile)       AS '儿童档案数',
  (SELECT COUNT(*) FROM schedule_info)       AS '排班数',
  (SELECT COUNT(*) FROM reserve_order)       AS '预约数',
  (SELECT COUNT(*) FROM vision_test_record)  AS '视力记录数',
  (SELECT COUNT(*) FROM sync_log)            AS '同步日志数',
  (SELECT COUNT(*) FROM sys_operation_log)   AS '操作日志数';
```
