# Careld 可尔欧得视力养护服务信息系统

## 项目概述

Careld可尔欧得线下视力养护门店统一云管理系统，覆盖总部运营、门店医护、家长、门店电视测视力四大角色，实现儿童视力电子档案、预约排班、养护前后视力检测、数据统计分析全流程线上化。

## 快速开始

### 环境要求

- Java 17+
- Node.js 18+
- MySQL 8.0+
- Redis 6.0+
- Android Studio (TV APK开发)

### 本地启动

```bash
# 1. 启动后端
cd backend/careld-server
./mvnw spring-boot:run

# 2. 启动前端（以门店Web为例）
cd frontend/store-web
npm install
npm run dev

# 3. TV APK使用Android Studio打开 tv-apk/ 目录
```

## 核心功能

1. **电子档案管理** - 儿童视力档案全生命周期管理
2. **预约排班** - 养护服务预约与技师排班
3. **电子视力表** - TV端标准对数视力表测量
4. **离线同步** - TV端断网缓存、联网自动同步
5. **数据分析** - 门店客流、视力改善统计报表
